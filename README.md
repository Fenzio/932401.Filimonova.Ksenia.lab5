# 932401.Filimonova.Ksenia.lab5

## О себе — Искусство и креатив

Лабораторная работа №5. Манипуляции с DOM деревом и сохранение состояния через localStorage.

**Автор:** Филимонова Ксения, группа 932401

## Что реализовано

- **Поиск элементов:** использование `getElementById`, `querySelector`, `querySelectorAll`.
- **Манипуляции с DOM:** изменение текста, классов, добавление и удаление элементов (`createElement`, `remove`).
- **Переключение темы:** кнопка для смены светлой/тёмной темы (класс `dark-theme` на `<body>`).
- **Скрытие/показ блоков:** кнопка «Скрыть хобби» с классом `hidden`.
- **Переключение вида:** кнопка «Переключить вид» (классы `view-grid` / `view-list`).
- **Добавление элементов:** кнопка «Добавить хобби» (запрашивает название через `prompt`, создаёт новый блок `<div>`).
- **Обработка ошибок:** проверка существования элементов перед выполнением действий.
- **localStorage:** сохранение списка хобби, темы, вида списка и состояния скрытия. Восстановление при перезагрузке страницы.

## Как открыть

Открыть файл `lab5/index.html` в любом браузере. 
*Для корректной работы скриптов (prompt, alert) и localStorage рекомендуется запускать через локальный сервер (например, расширение Live Server в VS Code).*
